# Bento web control plane

Scope: all apps/web/src surfaces; focus on overview, applications, app data and forms. Mode: Operate. Single-host operator needs quick condition scanning and safe, intelligible actions. Preserve routes, state and confirmations.

## Direction contract

THESIS: Bento as a functional compartmentalized tray: each task has a distinct, sized place and the arrangement itself helps the operator read. Refuse the generic card-and-table admin layout, and refuse decorative food illustration.
OWN-WORLD: A soft rice-colored workspace and a darker tray frame with purposeful compartment seams. Cells vary in size by priority, not by arbitrary decoration. Jade for actions, persimmon for exceptions, muted blue for information; calm typography and durable high-contrast states. Controls share one size and rhythm; information clusters by meaning.
STORY: The operator sees the stack condition, then exceptions and applications as individually actionable compartments. An app opens into operational compartments; data bindings show actual identities, databases and paths as structured objects. Forms move through identity, runtime, routing, data and resources without mixing unrelated fields.
FIRST VIEWPORT: The overview is a true tray layout: one broad condition compartment at top, below a large attention cell beside smaller stack-service cells, then application tiles and recent activity. Applications is a responsive grid of individual resource boxes, never table rows. Detail data is a set of binding compartments with explicit database chips and add actions; mobile stacks compartments without horizontal clipping.
FORM: User-pinned Bento compartment system, overriding seed 081a49e0. Signature interaction: choosing an application opens its own clearly partitioned workspace; active and pending states remain attached to that resource. Motion only conveys change, in short reduced-motion-aware transitions.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
