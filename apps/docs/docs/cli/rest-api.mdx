title: REST API
description: The /api/v1 HTTP API behind the UI and CLI.

The API is served on the loopback management listener under `/api/v1`. Types are defined in Go
(`apps/backend/internal/api/dto`) and generated for TypeScript with tygo.

## Conventions

- **JSON only.** Unknown fields, trailing data, wrong types, and bodies over 1 MiB are rejected.
- **Errors:** `{"error":{"code","message","fields"}}` with stable codes — `validation`, `not_found`, `conflict`,
  `precondition_failed`, `confirmation_required`, `unauthorized`, `forbidden`, …
- **Long-running mutations** return `202` with `{operation, statusUrl}` and a `Location` header. Send
  `Idempotency-Key` to make retries safe.
- **Browser writes** need the session cookie, an exact allowed `Origin`, and `X-CSRF-Token`.
- **API tokens** (`Authorization: Bearer bento_pat_…`) need no CSRF header and are limited to their scope
  (`read`, `operate`, `admin`); see [AI agents (MCP)](/cli/ai). Routes outside every scope return `403`.
- **Timestamps:** RFC 3339 UTC with milliseconds.

## Endpoints

| Area | Endpoints |
| --- | --- |
| Session | `GET/POST/DELETE /session`, `PUT /auth/password` |
| API tokens | `GET/POST /tokens`, `DELETE /tokens/{id}` (session or CLI only; `POST` returns the token once) |
| System | `GET /system`, `GET /catalog`, `GET /reconcile` |
| Apps | `GET/POST /apps`, `GET/PATCH/DELETE /apps/{id}`, `POST /apps/{id}/{start,stop,restart,publish,unpublish}` |
| App data | `POST /apps/{id}/bindings`, `POST /apps/{id}/bindings/{bid}/databases`, `POST /apps/{id}/permissions` |
| App files | `GET /apps/{id}/files?path=`, `GET/PUT/PATCH /apps/{id}/files/content` (admin; `~/app` only, no hidden paths) |
| App tools | `GET /apps/{id}/readiness`, `GET /apps/{id}/logs` (SSE), `POST /apps/{id}/exec`, `POST /apps/{id}/scheduler/command`, `GET /apps/{id}/terminal` (WebSocket) |
| App scheduler | `GET/POST /apps/{id}/scheduler/jobs`, `PATCH /apps/{id}/scheduler/jobs/{name}`, `POST /apps/{id}/scheduler/jobs/{name}/run`, `POST /apps/{id}/scheduler/jobs/{name}/enabled`, `POST /apps/{id}/scheduler/workers/{name}/{start,stop,restart}`, `GET /apps/{id}/scheduler/runs`, `GET /apps/{id}/scheduler/runs/{run}/log`, `POST /apps/{id}/scheduler/runs/{run}/stop` |
| Operations | `GET /operations`, `GET /operations/{id}`, `GET /operations/{id}/events` (SSE), `POST /operations/{id}/cancel` |
| Data | `GET/POST /services`, `GET /retired`, `POST /retired/{id}/prune` |
| Ingress | `GET/PUT /edge`, `GET /tunnel`, `PUT /tunnel/token`, `GET/POST /hosts`, `PUT/DELETE /hosts/{name}` |
| Database backups | `GET /backups/artifacts`, `GET /backups/runs`, `POST /backups`, `POST /backups/restore`, `GET/POST /backups/schedules`, `GET/PUT/DELETE /backups/schedules/{id}`, `POST /backups/schedules/{id}/enabled` |
| rclone | `GET /backups/rclone`, `POST /backups/rclone/test`, `GET /backups/rclone/terminal` (WebSocket) |
| Stack | `POST /stack/export` |

### App backups (restic)

| Endpoint | Notes |
| --- | --- |
| `GET /backups/apps` | Every app's summary and recent runs |
| `GET/PUT /apps/{id}/restic` | Settings |
| `POST /apps/{id}/restic/init` | Returns the key **once** |
| `POST /apps/{id}/restic/connect` | Connect an existing repository |
| `POST /apps/{id}/restic/{backup,refresh,check,unlock}` | Run, refresh snapshots, verify, remove stale locks |
| `POST /apps/{id}/restic/keys` | Confirmation `export <slug>`; returns the key once |
| `DELETE /apps/{id}/restic/keys/{keyId}` | Remove a key |
| `POST /apps/{id}/restic/inspect`, `POST /apps/{id}/restic/clone` | Clone needs `clone <new-slug>` |
| `POST /apps/restore-from-backup/inspect`, `POST /apps/restore-from-backup` | Another stack's repository; `clone <new-slug>` |

MCP is served at `POST /mcp` (outside `/api/v1`) for API tokens; see [AI agents (MCP)](/cli/ai).

The `/scheduler` routes above are a typed view of the app's minicrond for API tokens: they need the app running, show
job env keys but never values, and cannot delete or import jobs (use the UI or `POST /apps/{id}/scheduler/command`
from a session or the CLI). Creating and editing jobs needs `admin`. The scheduler UI is not part of the JSON API: it is proxied at `/apps/<slug>/scheduler/…` and needs a browser session
and an exact allowed `Origin`. When an app's `minicrond` setting is off, the `/scheduler` routes answer `409`
`precondition_failed` and the proxied UI answers `503`.

Apps carry two service switches: `valkey` (the app's own Valkey, default `false`) and `minicrond` (its scheduler,
default `true`). Both are accepted by `POST /apps` and `PATCH /apps/{id}`; changing either replaces a running app's
container.
