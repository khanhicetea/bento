Bento turns one Linux server into a small, tidy platform for your web apps. You create an app in the web UI, pick its
runtime, hostname, and database, deploy from git — and Bento runs it in its own container, under its own user, with
its own credentials.

## What you can do

| | |
| --- | --- |
| **Run apps** | PHP 7.4–8.5, or Node.js, Bun, and Python HTTP servers. One container per app. |
| **Deploy** | Connect a git repository, press **Deploy**, or deploy on every push. |
| **Go online** | Add a domain, get a free HTTPS certificate, publish with one click. |
| **Store data** | MySQL, PostgreSQL, SQLite, and Redis, with credentials injected for you. |
| **Run jobs** | Cron jobs and queue workers per app. |
| **Back up** | Scheduled database dumps and encrypted whole-app snapshots, off-site. |

## Is Bento right for you?

Bento is built for **one server** run by a developer or a small team — a VPS or a dedicated box hosting a handful of
Laravel, WordPress, Symfony, or Node apps. It is not a cluster scheduler: no replicas, no autoscaling, no
zero-downtime rollouts, and no hostile multi-tenant hosting.
