## By design

- **One host.** No replicas, autoscaling, or zero-downtime replacement — restarts and boot-config changes interrupt
  the app.
- **Shared apps network.** Apps on the same stack can reach each other's listeners.
- **Trusted code only.** Not a sandbox for hostile tenants. Curated runtime images only.
- **Loopback management.** Remote access needs your own secure tunnel.
- **Generated web config.** App Nginx and FPM config is generated; customization is through edge drop-ins and
  `.user.ini`. Access logs go to the bounded container log; edge hosts with the access log on also get an hourly
  [traffic report](/ingress/traffic) of page requests (30 days). App-local Nginx access logs have no report.

## Not yet verified

Verified end to end on **linux/amd64 and linux/arm64** (Debian 13, Docker 29) with PHP 7.4 and 8.4, Node.js 22 and
24, Bun 1.3, Python 3.13, MySQL 8.4 and PostgreSQL 18: Let's Encrypt certificates, HTTP/3 and IPv6 on the edge, a
Cloudflare Tunnel, GitHub and Gitea push to deploy, and backups to S3-compatible storage. Not yet exercised end to end:

- other runtime and database versions (their images build and pass the image tests)
- GitLab and Bitbucket webhooks
