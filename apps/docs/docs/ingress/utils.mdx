---
title: Utils
description: Bento's small public-safe listener for deploy webhooks and the database browser.
---

Two features need to be reachable from outside the SSH tunnel: **push-to-deploy webhooks** (called by your git host)
and the **database browser**. Bento serves them on a separate **utils listener** that exposes nothing else — never the
UI or the API. Every request must prove itself (a webhook secret, or a one-time browser ticket).

## Addresses

**Ingress → Utils → Utils listener** shows where it listens:

| Address | Reachable from |
| --- | --- |
| `127.0.0.1:7781` | the server itself (host nginx, Caddy) |
| apps-network address, e.g. `10.200.0.128:7781` | containers: the edge, cloudflared |

## Expose it

<Tabs>
  <Tab title="Bento edge">
    Webhooks work automatically on every domain the edge serves. The database browser is **not** forwarded on app
    domains. To serve both on a domain of their own, enter it under **Ingress → Utils → Edge host** and press
    **Serve on edge**. That adds this [host](/ingress/hosts) for you (you can also add it by hand):

    | Field | Value |
    | --- | --- |
    | Host | `utils.example.com` |
    | Target | **Upstream** → the apps-network address above, e.g. `http://10.200.0.128:7781` |
    | Path prefixes | `/_bento/` |
    | TLS | **ACME**, HTTPS redirect on |
    | Body limit | `80` |

    Every other path on that domain gets a 404 from the edge. While **Utils base URL** is empty, Bento uses this
    host's URL for webhook URLs and the database browser. If the stack's network plan changes, **Edge host** offers
    **Update address**.
  </Tab>
  <Tab title="Host nginx">
    ```nginx
    location /_bento/ {
      proxy_pass http://127.0.0.1:7781;
      proxy_set_header X-Forwarded-Proto $scheme;
      client_max_body_size 80m;
      proxy_read_timeout 15m;
    }
    ```
  </Tab>
  <Tab title="Cloudflare Tunnel">
    Add a hostname with path `^/_bento/` and service `HTTP` → the apps-network address. If `ufw` blocks
    container-to-host traffic: `ufw allow from 10.200.0.0/24 to any port 7781 proto tcp`.
  </Tab>
</Tabs>

Then set **Utils base URL** to the origin you exposed (e.g. `https://utils.example.com`). Bento uses it to show full
webhook URLs and to open the database browser. Always use HTTPS.

## Database browser

**Database browser → Enable** starts one shared Adminer container on the private data network. Then use **Browse** on
any binding in an app's [Data tab](/apps/data#browse-data).
