---
title: Backup
description: Protect one app — encrypted snapshots of its files and every database, restored in place or into a new app.
---

The **Backup** tab sets up the app's [app backup](/backups/app-backups): an encrypted restic repository on a remote,
holding the app's code, uploads, `.env`, scheduled jobs, and a dump of every database bound to it. Only changes are
uploaded after the first snapshot.

| Restore | How |
| --- | --- |
| One database, **in place** | **Restore DB** on a snapshot — [Restore a database](/backups/database) |
| The whole app, **into a new app** | **Clone** on a snapshot — never over the live one |

## Set it up

<Steps>
  <Step title="Choose a repository">
    You need an rclone remote first (**Backups → Remotes → Open shell**, `rclone config`). Then set **Repository**
    to `remote:path`, e.g. `b2:bento/apps/shop` — one path per app.
  </Step>
  <Step title="Choose what to save">
    Keep **Paths** as `.` (the whole home) unless you have a reason not to. Add **Excludes** like `node_modules`, and
    list **SQLite files** so they're copied safely while in use.
  </Step>
  <Step title="Set schedule and retention">
    A **Cron** schedule (server time zone) and how many hourly / daily / weekly / monthly snapshots to **Keep**.
  </Step>
  <Step title="Create the repository">
    Press **Create repository**. It is encrypted with the [stack backup password](/backups#stack-backup-password),
    the same for every app of this stack. To use a repository that already exists, enter its key under
    **Existing** and press **Connect** — leave the key empty to use the stack backup password.
  </Step>
</Steps>

<Callout type="danger">
Print the stack backup password on the host with `sudo bento backup password` and keep a copy **off the host**. If
it is lost, the backups cannot be recovered.
</Callout>

**Snapshots** lists every backup. Each one has **Restore DB** (replace one database of this app, type
`replace <database>`) and **Clone** (restore into a new app, type `clone <new-slug>`). Full details, including
restoring on another server: [App backups](/backups/app-backups).

**Access keys → Add** creates an extra key for this repository, e.g. for another server. Type `export <slug>` to
confirm; the key is shown **once**.
