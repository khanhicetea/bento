Bento helps you run several PHP apps and reverse-proxied services on one Linux server. You operate it with a local CLI. Bento generates a private Docker Compose stack and exposes only Nginx by default.

## Is Bento a fit?

Bento is designed for a technically capable developer or small team that:

- operates one Linux VPS or dedicated server;
- needs several PHP applications, or HTTP services behind a reverse proxy;
- wants a local CLI and Docker Compose rather than a resident web control plane;
- accepts shared, versioned PHP containers with per-app identities, pools, sockets, homes, and database grants.

Bento is not a cluster orchestrator or a hostile multi-tenant sandbox. It does not replace off-host backups, DNS management, source control, or your application's deployment procedure.

## How Bento works

```text
Operator -> bento CLI -> desired state -> generated configuration -> Docker Compose
Internet -> Nginx -> app PHP-FPM socket or reverse-proxy upstream
                       -> private MySQL, PostgreSQL, and Redis services
```

The `bento` command runs on the host only when you call it. It does not need a background daemon.

The stack root stores your intent and mutable stack data. Bento can replace generated files. You must protect app homes, certificates, backups, and database volumes.
